# 🖼️ Convert PNG to Base64

Esta es una aplicación web sencilla construida con **React**, **TypeScript** y **Vite** que permite convertir imágenes PNG a su representación en formato Base64.

🔗 [Ver la demo en vivo](https://maxenocmn.github.io/ConvertPNGtoBase64/)

## 🎯 Propósito

El propósito de esta app es proporcionar una herramienta rápida y accesible para codificar imágenes PNG en Base64 directamente desde el navegador, sin necesidad de instalar software adicional.

Esto puede ser útil para:

- Insertar imágenes en HTML o CSS sin usar archivos externos.
- Compartir imágenes embebidas por texto.
- Integrar recursos en correos electrónicos o JSON.

## ⚙️ Tecnologías utilizadas

- ⚛️ React
- ⚡ Vite
- 🟦 TypeScript
- 🎨 HTML5 / CSS3
